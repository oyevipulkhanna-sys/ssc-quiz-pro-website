# SSC QUIZ PRO Website

A responsive, bilingual (Hindi/English) static website starter for SSC preparation. Includes sample quizzes, a percentage calculator, a Pomodoro-style timer, notes/resource placeholders, and a light theme.

## Publish free with GitHub Pages
1. Create a GitHub repository, e.g. `ssc-quiz-pro-website`.
2. Upload **the contents of this folder** to the repository root (so `index.html` is at the root, not inside another nested folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then Save.
6. Wait for the Pages deployment. The public URL appears in Settings → Pages.

Alternative: add a GitHub Actions Pages workflow, but branch deployment is simplest for this static site.

## Current limitations
- The quiz bank contains a small set of demonstration questions, not a complete SSC question bank.
- Notes cards are placeholders.
- Quiz scoring is session-only; no cloud sync, multiplayer or leaderboard is implemented.
- The timer uses a browser alert when the session ends.
